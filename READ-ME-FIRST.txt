1. COPY over the repo, keeping the path:

       modules/market-tracker/market-tracker.js

   If you haven't yet uploaded the previous zip, do that one first — this
   file supersedes its copy of market-tracker.js, but that zip also carried
   market-tracker.css, assets/js/data.js and README.md, which this one does
   not.

   What changed: the line under a competitor box used to collapse four
   different reasons into "already shown to you before", which had a first
   run claiming you'd been shown things the box had never fetched. They are
   now reported separately:

       N older than 30 days
       N recorded as a baseline for next time
       N already on the site last time
       N already shown to you before
       N whose publish date couldn't be confirmed

2. DEPLOY THE WORKER — this carries the real fix.

       cd C:\Users\Tyler\customer-tracker
       npx wrangler deploy

   src/index.js, src/competitor.js and src/shared.js are already written to
   that folder.

   Off-site items (Medium, Substack, Reddit, HN) are now opened and their
   publish date read from the page, the same way pages on the competitor's
   own site already were. The model's date is only a hint and loses to the
   page. An article whose page can't be opened is dropped rather than shown
   with a date that might be wrong — the count of those appears in the line
   above, so an empty section explains itself.

   Expect competitor runs to take a little longer: up to 16 extra page
   fetches, five at a time.
